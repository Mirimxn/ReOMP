# ReOMP Mod Manager

The current build is an empty desktop shell. The Mod Manager will install OMP into the game and provide the interface for installing mods.

From this directory, run `npm ci` to install dependencies and `npm run tauri dev` to open the app. Run `npm run build` to check the frontend on its own. The desktop shell also requires Rust and the [Tauri platform prerequisites](https://v2.tauri.app/start/prerequisites/).
