# Mod Manager installers

Platform installers set up the desktop mod manager. The manager handles installation of OMP and mods into the game.

- Windows: an NSIS setup executable built by GitHub Actions. [Windows installer project](windows/)
- `linux/setup-linux.sh` is the inherited Steam Deck script for testing the OMP payload. [Steam Deck test notes](../notes/installer/Linux-SteamDeck-Install.md)
